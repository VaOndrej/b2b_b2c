Hranice portfolia — jedna appka, jeden primitiv

Appky si nesmí splývat. Když se ptáš „kterou appkou to vyřeším?“, nikdy neptej podle marketingové škatulky (spousta appek „zvedá AOV“). Ptej se „čí je to primitiv?“ — každá Won appka vlastní právě jeden a na cizí nesahá. Tím se ti nikdy nepřekryjí.

Won Stepper ovladač množství + živý cart-count (UX „kolik kusů“) cenu
Won Companion doporučení „přidej ještě jinou věc“ — cross-sell, bundle, bigger-pack swap (šířka) cenu
Won Tiers cenu podle množství — „kup víc toho samého, levněji“ (hloubka), Shopify Function = zdroj pravdy doporučování / UX

Test proti splývání: Stepper vlastní ovladač, Tiers vlastní cenu, Companion vlastní doporučení, Rewards vlastní odměnu, Badges vlastní štítek. Když appka potřebuje cizí primitiv, odkáže ho, nevlastní.

Množství = Stepper rozhodnuto 2026-08-07

„Quantity rules“ (MOQ / násobky / max) nejsou samostatná appka — samostatná „Won Quantity“ se ruší. Merchant to vnímá jako jednu věc: jak zákazník volí kolik kusů.

Stepper Free = widget + živý count. Stepper Pro = + pravidla množství (MOQ / násobky / max) přes won.quantity_rules. Stepper stále nesahá na cenu — jen na povolené počty.

Companion ≠ Tiers rozhodnuto 2026-08-07

Vypadají podobně (oba „upsell“), ale je to šířka vs hloubka. Neslévat. Tiers drží cenu Functionou a patří do Function-rodiny s Rewards (sdílený packages/functions crate) — vnořit ho do Companionu = zašpinit jeho duši „žádná cenová magie“.

Companion Tiers místo toho odkazuje: „přidej ještě 1 ks a jsi v levnějším tieru“ = Companion doporučení namířené na cenu, kterou vlastní Tiers. Kooperují, neslévají se.

Sdílený cart-core (@won/core/cart): Stepper je appka, která staví optimistickou páteř celé suite. Konzumuje cartState (reaktivní store, jediný zdroj pravdy = snapshot /cart.js) a cartAdapter (wrap fetch+XHR na /cart/(add|change|update|clear).js + theme pub/sub → reconcile → NormalizedCartEvent), ale vlastní a dodává dva stěžejní díly: optimistic.mutate(op) (okamžitý next-state do cartState → reálný /cart/*.js → reconcile z /cart.js → rollback při chybě/timeoutu; idempotence proti dvojkliku; re-sync mezi taby; ignoruje _gift_progress) a zpevnění adapteru pro Dawn i Horizon (quick-add, Section Rendering API, multi-tab). cartState, deriveEvents a milestone state machine zdědil Toasts pilot — tady se zúročí; Companion a Rewards na hotovém core jen stojí a referencují „viz Won Stepper".
