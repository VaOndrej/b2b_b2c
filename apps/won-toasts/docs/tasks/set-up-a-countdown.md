# Set up a countdown timer

1. Go to **Toasts** → **Countdown timer**.
2. Turn on **Show a countdown**.
3. Choose what it counts to:
   - **Fixed end date** — set **End date**. Everyone sees the same deadline.
   - **Evergreen** — set **Restart for each visitor after**. Each visitor gets
     their own window from their first visit.
4. Save.

## What it will not do

The countdown only ever counts to a date you set. It cannot generate a fake
deadline, and when a fixed end date passes it stops showing rather than looping.

If you use the evergreen mode, be honest about what the deadline means — the app
enforces the mechanics, not your copy.

## Pair it with a real discount

Like every toast, this **announces**; it does not create the offer. Set the actual
discount in Shopify so the deadline the shopper sees and the discount that applies
end at the same moment.
