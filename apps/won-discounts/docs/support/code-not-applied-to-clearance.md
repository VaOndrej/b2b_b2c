# A discount code did not apply to a clearance item

By default a clearance item takes **no other Won discount**: not a product
discount, not a code, and it is left out of order discounts. The rest of the
cart gets them as usual.

To let clearance items take other discounts too, switch on **Clearance with
other discounts** in **Settings**. The quantity tiers table then also shows
for a variant on sale. See [../concepts/combining-discounts.md](../concepts/combining-discounts.md).
