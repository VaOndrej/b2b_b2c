# Switch combination categories in Settings

By default Won combines discounts one fixed way: product discounts on the
same item compete (the better one wins), product discounts add up with order
and shipping discounts. See [combining-discounts](../concepts/combining-discounts.md).

1. Open **Settings → Combining discounts**.
2. For each category — clearance with anything, product with product, product
   with order, product/order with shipping — switch it between adding up and
   competing. Each switch explains in plain words what flipping it does.
3. Save. One save applies every change at once.

## Check the effect

Changing these switches can change what a shopper pays on carts that already
have several discounts. Before relying on a new setting, check it in
[try-a-cart](try-a-cart) with a cart that has more than one discount.

This setting is store-wide and available on Free. Choosing combinations **per
discount** (so discount A stacks with C but not B) is Pro; see
[pro-combinations](../concepts/pro-combinations.md).
