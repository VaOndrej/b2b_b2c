# Add a Won element to the theme code with AI

Use this where the theme takes no app block (the cart drawer, a product card in themes like Dawn) or where you
want an element somewhere a block cannot go. Won never changes your theme and never calls an AI itself.

1. On **Placement on your store** click **Prepare a brief for AI** (or **I want it elsewhere**) at the place.
2. **Copy the brief.** Click **Prepare the brief**, then **Copy the brief**. It says what to add, where and what
   not to change, and holds the current content of the theme file it is about.
3. **Paste it into your AI and save the result.** Any AI you can paste text into works. It answers with the whole
   changed file. Click **Open the file in the code editor**, paste the answer over the file's content and save.
   It is safer to do this in a copy of the theme first (**Online Store → Themes → … → Duplicate**): Won finds the
   element in a copy too and tells you it is *only in a copy* until you publish it.
4. **Check.** Click **Check again**. The row turns to **In the theme**.

## I'll do it myself

The second tab shows the one line to paste, the file it belongs in and its options. Nothing else goes around it:
Won fills the element, and an empty one takes no space. The full list of elements:
[theme-tags](../reference/theme-tags.generated.md).

## Notes

- The tiers table and the sale badge work only on the product page, for the product the page is about.
- To undo, delete the line from the file. An element Won no longer fills (for example after uninstalling) stays
  empty and takes no space.
- After a theme update replaces the file, the row says *Missing in the theme* again; repeat the steps.
